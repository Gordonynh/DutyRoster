# 值日提醒

到点主动弹出值日安排。

## 为什么是浮窗

值日提醒不显眼的结果就是没人真去值日。所以这个插件的目标是**让人一眼看到**，但不拦路：

- **人名用最大的字号** —— 需要被看到的是「谁」，不是「擦黑板」
- 置顶并反复重申，全屏应用也盖不住
- 停留十几秒后自己消失；**点屏幕任意位置**也能立刻关掉，不用去找按钮
- 可以拖走，但拖不出屏幕

刻意不做花哨动画：反复闪烁只会让人更快学会无视它。

## 两种形式

| | 默认形式 | 适用 |
|---|---|---|
| **日常时间点** | 卡片浮窗 | 擦黑板、倒垃圾这类每节课都有的 |
| **大扫除** | 整屏动画 | 全班参与的扫除，大标题「请值日生打扫」 |

两种都能在设置页里改成「卡片浮窗 / 整屏 / 只发 ClassIsland 提醒 / 不提醒」。
哪些算大扫除按**项目名**判断（默认「扫地」「拖地」），改了值日表的时间也不用回来改设置。

## 值日表

纯文本，用记事本就能改，保存后自动生效。位置：**设置 → 值日提醒 → 打开**。

```
[设置]
轮换起始 = 2026-01-05
轮换周期 = 7          # 天。有多个 [批次] 时按这个周期依次轮换

[第1批]
跳过 = 周六

周一
08:40  擦黑板：张三；倒垃圾：李四
11:30  擦黑板：张三；扫地：王五 赵六；拖地：钱七 孙八

周二~周五 周日
08:40  擦黑板：李四；倒垃圾：王五
```

规则：

- 以 `#` 开头的行和空行会被忽略
- **星期行**在前，下面的时间点都属于这些天。支持 `周一`、`周一 周三`、`周一~周五`、混写
- **时间行**：`时间  项目：人名 人名；项目：人名`
- 中英文冒号分号都认；人名之间空格、顿号、逗号、斜杠都行
- 写成 `08:40-08:50` 是**时间段**：提醒一直显示到 08:50，结束时间必须晚于开始时间
- 只写 `08:40` 是**单时刻**：弹出后按「弹窗停留」秒数消失
- 写错的行会在设置页里指出来（第几行、哪里不对），不会让整张表失效

## 设置

设置页顶部有两个标签页：**常规设置**放提醒行为，**值日表设置**放值日表本身（只读预览 + 可视化编辑）。

### 常规设置

| 项 | 默认 | 说明 |
|---|---|---|
| 启用值日提醒 | 开 | 总开关 |
| 提前提醒 | 0 分钟 | 提前多久弹 |
| 弹窗停留 | 17 秒 | **只对单时刻生效**；写成 `08:40-08:50` 的时段会一直显示到结束 |
| 触发延迟 | 26 秒 | 到点后再等几秒才弹，铃响完再提醒 |
| 弹窗提示音 | 开 | 到点播一声 |
| 关闭方式 → 点击空白处或按任意键关闭 | **开** | 卡片靠全局鼠标钩子，整屏靠窗口自身事件 |
| 关闭方式 → 按钮关闭 | **关** | 右上角的关闭按钮 |
| 日常提醒形式 | 卡片浮窗 | 也可整屏 / 只发提醒 / 不提醒 |
| 大扫除提醒形式 | 整屏 | 同上 |
| 哪些项目算大扫除 | 扫地、拖地 | 按**项目名**判断，改时间不用回来改设置 |
| 整屏动画颗粒 | 10 px | 每帧开销与格子数成正比，边长翻倍开销降到四分之一 |
| 整屏提醒的大标题 | 请值日生打扫 | |
| 弹窗位置 | 屏幕正中 | 也可顶部居中 / 右下角 |
| 弹窗大小 | **大** | 紧凑 / 标准 / 大 |
| 同时发 ClassIsland 提醒 | **开** | 主界面那条太窄且一晃就过，只作补充 |

**两个关闭方式都不勾**时，单时刻的提醒既不会自动消失、也不响应点击和按键，此时仍可按 `Esc` 关闭；
带结束时间的时间段到期照常关闭（结束时间是值日表内容的一部分，不算「用户关闭」）。
插件退出、或者下一次提醒触发时，提醒窗口也照常会被关闭——这三条不受上面两个复选框影响。

### 值日表设置

- **显示**：今天由哪批值日、每个时间点的时段 / 项目 / 人名 / 是否大扫除，外加值日表路径、「打开」「重新载入」按钮和解析错误提示。
- **配置**：可视化改值日表——选批次、勾星期（勾几天就写几天，这几天共用一份时间点）、增删时间点（开始 / 结束时间 + 项目 + 人名），最后点「保存到文件」。

> ⚠️ **保存会用插件生成的格式重写整个文件。**你手写的注释、空行和排版会丢失（原文件会先备份成 `值日表.txt.bak`）。
> 保存前会弹一条确认说明这一点。内容本身不会丢：连续内容相同的星期会被合并回 `周一~周五` 这样的写法，
> 所以文件不会因为可视化编辑而膨胀。
>
> 编辑器只在**你点「保存到文件」时**才写盘。用记事本改文件、改设置项都不会触发写回。
