# 值日提醒

到点主动弹出值日安排。

## 为什么是浮窗

值日提醒不显眼的结果就是没人真去值日。所以这个插件的目标是**让人一眼看到**，但不拦路：

- **人名用最大的字号** —— 需要被看到的是「谁」，不是「擦黑板」
- 置顶并反复重申，全屏应用也盖不住
- 停留十几秒后自己消失；**点屏幕任意位置**也能立刻关掉，不用去找按钮
- 可以拖走，但拖不出屏幕

刻意不做花哨动画：反复闪烁只会让人更快学会无视它。

## 两种形式

| | 默认形式 | 适用 |
|---|---|---|
| **日常时间点** | 卡片浮窗 | 擦黑板、倒垃圾这类每节课都有的 |
| **大扫除** | 整屏动画 | 全班参与的扫除，大标题「请值日生打扫」 |

两种都能在设置页里改成「卡片浮窗 / 整屏 / 只发 ClassIsland 提醒 / 不提醒」。
哪些算大扫除按**项目名**判断（默认「扫地」「拖地」），改了值日表的时间也不用回来改设置。

## 值日表

纯文本，用记事本就能改，保存后自动生效。位置：**设置 → 值日提醒 → 打开**。

```
[设置]
轮换起始 = 2026-01-05
轮换周期 = 7          # 天。有多个 [批次] 时按这个周期依次轮换

[第1批]
跳过 = 周六

周一
08:40  擦黑板：张三；倒垃圾：李四
11:30  擦黑板：张三；扫地：王五 赵六；拖地：钱七 孙八

周二~周五 周日
08:40  擦黑板：李四；倒垃圾：王五
```

规则：

- 以 `#` 开头的行和空行会被忽略
- **星期行**在前，下面的时间点都属于这些天。支持 `周一`、`周一 周三`、`周一~周五`、混写
- **时间行**：`时间  项目：人名 人名；项目：人名`
- 中英文冒号分号都认；人名之间空格、顿号、逗号、斜杠都行
- 写成 `08:40-08:50` 也认，但**只用前面那个时间点**来提醒
- 写错的行会在设置页里指出来（第几行、哪里不对），不会让整张表失效

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 启用值日提醒 | 开 | 总开关 |
| 提前提醒 | 0 分钟 | 提前多久弹 |
| 弹窗停留 | 15 秒 | 到时自动消失；点屏幕任意处也会立刻关 |
| 触发延迟 | 10 秒 | 到点后再等几秒才弹，铃响完再提醒 |
| 弹窗位置 | 屏幕正中 | 也可顶部居中 / 右下角 |
| 弹窗大小 | 标准 | 紧凑 / 标准 / 大 |
| 整屏动画颗粒 | 10 px | 每帧开销与格子数成正比，边长翻倍开销降到四分之一 |
| 同时发 ClassIsland 提醒 | **关** | 主界面那条太窄且一晃就过，只作补充 |

设置页里有「试弹一次」，可以直接看效果。
